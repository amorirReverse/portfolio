03 / À PROPOS

Du code jusqu'au système.

Je m'intéresse au développement logiciel lorsqu'il rencontre le monde réel : systèmes embarqués, communication entre composants et interfaces capables de représenter des données en temps réel.

Je travaille principalement avec C++, C, Python et Linux, avec un intérêt particulier pour les architectures où performance, fiabilité et lisibilité du code sont essentielles. J'explore également d'autres langages et technologies pour élargir mes compétences et m'adapter à différents environnements de développement.

Mon projet Car Dashboard illustre mon intérêt pour les systèmes embarqués : une application C++ connectée à un bus CAN virtuel, capable de recevoir et traiter des trames en temps réel avant de les restituer dans une interface graphique moderne.

À travers mes différents projets, je cherche à développer une approche polyvalente du développement logiciel, avec une spécialisation progressive vers les systèmes embarqués et le C/C++.
