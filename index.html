03 / À PROPOS

Du code jusqu'au système.

Je m'intéresse au développement logiciel lorsqu'il rencontre le monde réel : systèmes embarqués, communication entre composants et interfaces capables de représenter des données en temps réel.

Je travaille principalement avec C++, C et Linux, avec un intérêt particulier pour Qt / QML et les architectures où performance, fiabilité et lisibilité du code sont essentielles.

Mon projet Car Dashboard illustre cette approche : une application C++ connectée à un bus CAN virtuel, capable de recevoir et traiter des trames en temps réel avant de les restituer dans une interface graphique moderne.
